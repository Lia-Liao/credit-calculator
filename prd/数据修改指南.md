# 数据修改指南

## 管理后台访问

您可以通过以下地址访问管理后台：
- **http://localhost:3000/admin**

## 如何修改数据

### 方法一：通过管理后台（推荐）

1. 访问管理后台：http://localhost:3000/admin
2. 在管理界面中直接添加、编辑或删除信用卡和分期产品
3. 修改会自动保存，无需重启服务器

### 方法二：直接编辑 JSON 文件

数据存储在 `local/data/data.json` 文件中。

#### 1. 找到数据文件

```
local/data/data.json
```

首次运行后会自动创建这个文件。

#### 2. 编辑数据文件

用任意文本编辑器（VS Code、记事本等）打开 `data.json` 文件。

#### 3. 数据结构说明

```json
{
  "creditCards": [
    {
      "id": "bank_001",
      "bankName": "招商银行",        // 银行名称
      "bankLogo": "",
      "billAmount": 15000,         // 账单出账金额
      "creditLimit": 50000,        // 现金授信额度
      "products": [                 // 分期产品
        {
          "id": "prod_001",
          "productType": "bill",    // "bill"=账单分期, "cash"=现金分期
          "enabled": true,
          "term": 3,                // 期数（月）
          "rate": 0.045,            // 年化利率（小数，0.045=4.5%）
          "billAmount": 15000       // 账单分期金额（仅账单分期）
        },
        {
          "id": "prod_002",
          "productType": "cash",
          "enabled": true,
          "term": 3,
          "rate": 0.052,
          "minAmount": 1000,        // 最低借款金额（仅现金分期，默认1000）
          "maxAmount": 50000        // 最高借款金额（仅现金分期）
        }
      ]
    }
  ]
}
```

#### 4. 分期产品字段说明

| 字段 | 账单分期 | 现金分期 |
|------|----------|----------|
| productType | bill | cash |
| term | 必填 | 必填 |
| rate | 必填 | 必填 |
| billAmount | 必填（出账金额） | 不适用 |
| minAmount | 不适用 | 必填（默认1000） |
| maxAmount | 不适用 | 必填 |

#### 5. 修改示例

##### 添加新信用卡
在 `creditCards` 数组中添加新对象：
```json
{
  "id": "bank_003",
  "bankName": "建设银行",
  "bankLogo": "",
  "billAmount": 20000,
  "creditLimit": 60000,
  "products": []
}
```

##### 修改现有信用卡数据
直接修改对应字段的值即可。

##### 添加账单分期产品
```json
{
  "id": "prod_011",
  "productType": "bill",
  "enabled": true,
  "term": 12,
  "rate": 0.045,
  "billAmount": 20000
}
```

##### 添加现金分期产品
```json
{
  "id": "prod_012",
  "productType": "cash",
  "enabled": true,
  "term": 12,
  "rate": 0.048,
  "minAmount": 1000,
  "maxAmount": 60000
}
```

#### 6. 保存并生效

1. 保存 `data.json` 文件
2. 重启服务器（如果服务器正在运行）
   - 在终端按 `Ctrl+C` 停止
   - 然后运行 `pnpm dev` 重新启动
3. 刷新浏览器页面即可看到更新

## Cloudflare KV 数据同步（生产环境）

在 Cloudflare Pages 生产环境中，数据存储在 KV 命名空间中：

1. 在 Cloudflare Dashboard 中进入 KV 命名空间
2. 创建或更新 `data` 键
3. 值为完整的 JSON 数据

## 注意事项

- **id 必须唯一**：每个信用卡和产品都需要唯一的 id
- **利率格式**：使用小数（0.045 表示 4.5%）
- **备份文件**：修改前建议先备份 `data.json`
- **数据一致性**：通过管理后台修改会自动保存，无需手动编辑文件
