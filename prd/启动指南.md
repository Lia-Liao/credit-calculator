# 启动指南

## 解决 PowerShell 执行策略问题

由于 Windows PowerShell 默认禁止运行脚本，您需要先临时允许执行策略。

### 方法一：使用 CMD（推荐）

1. 打开命令提示符（CMD），不是 PowerShell
2. 进入项目目录：
```cmd
cd d:\AIprogram\trae\DataAnalysis\test0331\credit-calculator\backend
```

3. 安装依赖：
```cmd
npm install
```

4. 启动服务：
```cmd
npm start
```

### 方法二：临时更改 PowerShell 执行策略

如果您必须使用 PowerShell，可以在当前会话中临时允许：

1. 打开 PowerShell
2. 运行以下命令（仅对当前窗口有效）：
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

3. 然后安装依赖：
```powershell
cd d:\AIprogram\trae\DataAnalysis\test0331\credit-calculator\backend
npm install
```

4. 启动服务：
```powershell
npm start
```

### 方法三：创建一个启动脚本

我已经为您创建了 `install.bat`，您可以：
1. 双击 `backend/install.bat` 来安装依赖
2. 然后在 cmd 中运行 `npm start`

## 访问应用

启动成功后，您可以访问：
- 前端页面: http://localhost:3000
- 管理后台: http://localhost:3000/admin

## npm install 工作原理回顾

- **package.json** = 购物清单
- npm 只安装清单上的包及其依赖
- 不会安装 npm 仓库中的所有包
