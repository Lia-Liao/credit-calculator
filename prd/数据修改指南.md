# 数据修改指南

现在您可以通过以下地址访问管理后台：
- **http://localhost:3000/admin** （已修复！）

## 如何修改数据（JSON 文件方式）

由于我们改用了简单的 JSON 文件存储，修改数据非常简单！

### 1. 找到数据文件

数据存储在：`backend/data/data.json`

首次运行后会自动创建这个文件。

### 2. 编辑数据文件

用任意文本编辑器（VS Code、记事本等）打开 `data.json` 文件。

### 3. 数据结构说明

```json
{
  "creditCards": [
    {
      "id": 1,
      "bankName": "招商银行",           // 银行名称
      "bankLogo": "",
      "billAmount": 15000,            // 账单出账金额
      "creditLimit": 50000,            // 现金授信额度
      "products": [                     // 分期产品
        {
          "id": 1,
          "productType": "bill",       // "bill"=账单分期, "cash"=现金分期
          "enabled": true,
          "term": 3,                    // 期数（月）
          "rate": 0.045,                // 年化利率（小数，0.045=4.5%）
          "minAmount": 1000,            // 最低借款金额
          "maxAmount": 50000            // 最高借款金额
        }
      ]
    }
  ]
}
```

### 4. 修改示例

#### 添加新信用卡
在 `creditCards` 数组中添加新对象：
```json
{
  "id": 3,
  "bankName": "建设银行",
  "bankLogo": "",
  "billAmount": 20000,
  "creditLimit": 60000,
  "products": []
}
```

#### 修改现有信用卡数据
直接修改对应字段的值即可。

#### 添加分期产品
在对应信用卡的 `products` 数组中添加：
```json
{
  "id": 11,
  "productType": "bill",
  "enabled": true,
  "term": 12,
  "rate": 0.045,
  "minAmount": 1000,
  "maxAmount": 60000
}
```

### 5. 保存并生效

1. 保存 `data.json` 文件
2. 重启服务器（如果服务器正在运行）
   - 在终端按 `Ctrl+C` 停止
   - 然后运行 `pnpm start` 重新启动
3. 刷新浏览器页面即可看到更新

## 注意事项

- **id 必须唯一**：每个信用卡和产品都需要唯一的 id
- **利率格式**：使用小数（0.045 表示 4.5%）
- **备份文件**：修改前建议先备份 `data.json`
