# 启动指南

## 环境要求

- Node.js >= 16.x
- pnpm >= 8.x

## 启动步骤

### 1. 进入项目目录

```cmd
cd d:\AIprogram\trae\DataAnalysis\test0331\credit-calculator
```

### 2. 安装依赖

```cmd
pnpm install
```

### 3. 启动本地开发服务器

```cmd
pnpm dev
```

## PowerShell 执行策略问题解决

如果在 PowerShell 中遇到执行策略问题，可以：

### 方法一：使用 CMD（推荐）
直接使用命令提示符（CMD）执行上述命令。

### 方法二：临时更改执行策略
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
pnpm install
pnpm dev
```

## 访问应用

启动成功后，您可以访问：
- **前端页面**: http://localhost:3000
- **管理后台**: http://localhost:3000/admin

## Cloudflare Pages 开发（可选）

### 安装 wrangler
```cmd
pnpm install wrangler
```

### 开发模式
```cmd
pnpm pages:dev
```

### 部署到生产环境
```cmd
pnpm pages:deploy
```

## 命令说明

| 命令 | 说明 |
|------|------|
| `pnpm install` | 安装所有依赖 |
| `pnpm dev` | 启动本地 Express 服务器 |
| `pnpm pages:dev` | 启动 Cloudflare Pages 开发模式 |
| `pnpm pages:deploy` | 部署到 Cloudflare Pages |

## 停止服务

在终端按 `Ctrl+C` 即可停止服务器。
